## Development and provenance

DataCtrlLink was already a working, human-created plugin before AI-assisted
review began. The developer supplied their own addon and asked for help securing
their own code. No Tribute, PWM, CakeHook, WWE, or 2K proprietary source code
was copied into this release.

AI tools assisted with the security review and the later replacement's analysis,
implementation, testing, refactoring, and documentation. Third-party compiled
software was examined only as part of disclosed interoperability research. The
complete standing statement is in `DEVELOPMENT-AND-PROVENANCE-FAQ.md`.
